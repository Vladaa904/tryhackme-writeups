## 1. Разграничение прав доступа и векторы повышения привилегий
* **Модель прав доступа (`rwx`):** управление владельцами (`chown`) и правами (`chmod`) для владельца (`u`), группы (`g`) и остальных пользователей (`o`).
* **Критические риски безопасности:**
  * Наличие файлов с правами на запись для всех (`777`) в системных директориях.
  * Небезопасно настроенные права `sudo` (`/etc/sudoers`) или наличие бинарных файлов с установленным битом **SUID** (`find / -perm -4000 2>/dev/null`), позволяющих непривилегированному пользователю выполнить команды от имени `root`.

## 2. Мониторинг процессов и сетевой активности
Команды для первичной диагностики подозрительной активности на Linux-хосте (Debian / Astra Linux):
* `ps aux` / `top` — просмотр запущенных процессов, их владельцев (`PID`, `USER`) и аргументов запуска.
* `ss -tulnp` — проверка открытых сетевых портов и сокетов с привязкой к конкретным процессам.
* `crontab -l` и проверка `/etc/crontab` — поиск скрытых задач планировщика, используемых для закрепления в системе (Persistence).

## 3. Журналы событий безопасности (Log Analysis)
Основные директории и файлы журналов в `/var/log/` для расследования инцидентов:
* `/var/log/auth.log` (Debian/Ubuntu) — события аутентификации, входы по SSH, использование команды `sudo`.
* `/var/log/syslog` — общие системные события и ошибки служб.
* **Пример поиска попыток перебора паролей по SSH:**
  ```bash
  grep "Failed password" /var/log/auth.log | awk '{print \$(NF-3)}' | sort | uniq -c | sort -nr
  ```
