# TryHackMe Write-ups & SOC Incident Reports

Коллекция структурированных отчётов по прохождению практических лабораторий и симуляций реагирования на инциденты (Blue Team / Defensive Security) на платформе **TryHackMe**.

Каждый отчёт составлен по стандарту расследования инцидентов и анализа защищённости:
1. **Описание задачи / инцидента** (контекст).
2. **Ход расследования и анализ** (логи, протоколы, векторы атак).
3. **Выявленная причина (Root Cause)**.
4. **Рекомендации по устранению и защите (Remediation)**.
