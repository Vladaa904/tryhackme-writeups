# TryHackMe Write-ups & SOC Incident Reports

Коллекция структурированных отчётов по прохождению практических лабораторий и симуляций реагирования на инциденты (Blue Team / Defensive Security) на платформе **TryHackMe**.

Каждый отчёт составлен по стандарту расследования инцидентов:
1. **Описание инцидента / задачи** (контекст).
2. **Ход расследования** (проанализированные логи, артефакты и инструменты).
3. **Выявленная причина (Root Cause)** и индикаторы компрометации (IoC).
4. **Рекомендации по устранению (Remediation)**.
